# NasDrive 系统介绍

## 1. 定位

NasDrive 是一个运行在 Windows 10/11 上的开源工具，把 NAS（网络存储）上的文件夹映射成本地盘符，让任何程序都能像访问本地磁盘一样读写 NAS 上的文件。功能上对标 RaiDrive，支持三种连接方式：

- **WebDAV**：通用的 HTTP 文件访问协议，几乎所有 NAS 和网盘服务都支持；
- **NFS v3**：Unix/Linux 世界的网络文件系统，局域网内高效；
- **群晖 Synology**：直接调用 DSM 的 File Station Web API，无需在 NAS 上开启额外服务，支持两步验证。

## 2. 总体架构

```
┌────────────────────────────── Windows（当前用户，非管理员） ──────────────────────────────┐

│  │ 主窗口 / 添加编辑 / 设置      │  HTTP +    │ rc 控制接口（127.0.0.1，随机端口，随机口令）│   │
│  │ 托盘图标与菜单               │  Basic认证 │ mount/*  vfs/*  nasdrive/*                │   │

│                                              │  │ webdav     │ nfs（自研）   │ synology │  │   │
│                                              │  │ (rclone)   │ + nfsclient   │ （自研） │  │   │
│                                              └──┴─────┬──────┴──────┬───────┴────┬─────┴──┘   │

```

### 2.1 两个进程

| 进程 | 语言 | 职责 |
|---|---|---|
| `NasDrive.exe` | C# WPF | 界面、托盘、配置与凭据管理、驱动器状态机、引擎守护 |
| `nasdrive-engine.exe` | Go | rclone 引擎：协议后端、VFS 缓存、WinFsp 挂载，通过 rc（HTTP JSON）接口被控制 |

分开的好处：界面关闭或崩溃不影响已挂载的盘符；界面重启后通过 `engine.ready.json` + 凭据管理器中的 rc 口令重新接管正在运行的引擎；引擎崩溃时界面会自动重启它并重新连接驱动器（指数退避，最多 5 次）。

### 2.2 rclone 的使用方式

rclone 作为 Go 库被引用（未修改其源码），引擎只链接需要的部分：

- 后端：`webdav`、`local`（VFS 缓存需要），以及 NasDrive 自己的 `nfs`、`synology`；
- 命令：`cmount`（WinFsp 挂载）、rc 服务、`version`；
- 其余 70 余个存储后端与命令均不编译进程序。

挂载时不写 rclone.conf，而是使用"即时连接字符串"，例如：

```
:synology,url='https://nas:5001',user='bob',pass='<obscured>',device_id='<obscured>',override.no_check_certificate='true':/share
:nfs,host='nas',export='/volume1/share',uid='0',gid='0',privileged_port='true':/sub
:webdav,url='https://nas:5006',vendor='other',user='bob',pass='<obscured>',override.http_proxy='http://proxy:8080':/share
```

`override.*` 让每个驱动器拥有独立的超时、证书与代理设置。

## 3. 协议后端

### 3.1 WebDAV

直接使用 rclone 自带的 webdav 后端。

### 3.2 NFS（自研）

rclone 只有 NFS 服务端（`serve nfs`），没有客户端，因此 NasDrive 实现了：

- `engine/nfsclient`：纯 Go 的 NFSv3、MOUNT v3 与 portmapper 客户端。手写 XDR 编解码；每个 RPC 都有截止时间；连接断开自动重连，只对幂等操作自动重试；可从特权源端口（<1024）发起连接（群晖等 NAS 的默认要求，Windows 上无需管理员权限）。
- `engine/backend/nfs`：rclone 后端。READDIRPLUS 列目录；文件句柄缓存与 STALE 恢复；上传先写临时文件再 RENAME 原子替换；8 路并发预读/写入；服务端改名/移动；FSSTAT 提供真实容量。
- 通过 rclone 官方后端一致性测试（`fstests`，对进程内的 `rclone serve nfs`）。

### 3.3 群晖 Synology（自研）

`engine/backend/synology` 调用 DSM Web API：

| 功能 | API |
|---|---|
| 登录 / 注销 | SYNO.API.Auth v6（session=FileStation），会话过期自动重新登录 |
| 列共享 / 列目录 / 文件信息 | SYNO.FileStation.List（list_share / list / getinfo） |
| 下载（支持 Range） | SYNO.FileStation.Download |
| 上传（流式 multipart） | SYNO.FileStation.Upload |
| 新建文件夹 / 删除 / 改名 / 移动 | CreateFolder / Delete / Rename / CopyMove |
| 容量 | list_share 的 volume_status |

**两步验证**：首次登录返回"需要验证码"时界面弹框；用验证码登录并请求设备令牌（`enable_device_token`，与设备名 `NasDrive-电脑名` 绑定），立即用令牌再登录一次校验，然后把令牌加密保存在凭据管理器，此后登录无需验证码。

## 4. 关键设计

| 主题 | 做法 |
|---|---|
| 凭据安全 | 驱动器密码、群晖设备令牌、代理密码、引擎 rc 口令全部存入 Windows 凭据管理器；传给引擎前用 rclone obscure 处理；日志自动脱敏 |
| 不以管理员身份运行 | 提权进程挂载的盘符资源管理器看不到，因此检测到提权时自动经由资源管理器以普通身份重启自己；遗留的提权引擎会被替换 |
| 盘符显示 | 网络模式下写入 Explorer 的 `MountPoints2\##server#share\_LabelFromReg`，使盘符显示为"名称 (X:)"及容量 |
| 只读 | VFS 只读之外，再给 WinFsp 指定只读的安全描述符（`FileSecurity=D:P(A;;FRFX;;;WD)`），让 Windows 在打开文件时就拒绝删除——否则 Windows 的"关闭时删除"会吞掉错误，造成"删除成功"的假象 |
| 缓存 | rclone VFS full 模式：读写都经过本地缓存，写回延迟 5 秒；断开时检查上传队列 |
| 代理 | 引擎启动时清除 HTTP(S)_PROXY 环境变量，只使用 NasDrive 自己的、按驱动器启用的代理设置 |
| 托盘图标 | 每个尺寸（16–64 px）单独绘制并对齐像素，按当前 DPI 选择；底色表示状态 |
| 安装 | Inno Setup：检测并静默安装 WinFsp（失败则中止）；升级前结束正在运行的 NasDrive |

## 5. 引擎 rc 接口（NasDrive 专用部分）

| 接口 | 用途 |
|---|---|
| `nasdrive/version`、`nasdrive/health` | 版本、WinFsp 与缓存目录自检 |
| `nasdrive/test` | 测试连接字符串：登录、列目录、读取容量，返回分类后的错误码 |
| `nasdrive/mounts`、`nasdrive/probe` | 挂载列表与上传队列；在线探测 |
| `nasdrive/nfsexports` | 列出 NFS 服务器的导出 |
| `nasdrive/synologin` | 用两步验证码登录群晖并返回设备令牌 |
| `nasdrive/listdirs` | 列出子目录（群晖共享文件夹） |

`core/command` 已被禁用。

## 6. 测试

- Go 单元与一致性测试：`cd engine && go test ./...`
  - NFS 后端：rclone `fstests` 对进程内 `rclone serve nfs`；
  - 群晖后端：rclone `fstests` 对内置的模拟 DSM（含会话过期、两步验证与设备令牌）；
  - rc 接口：自签名证书下的两步验证登录等回归测试。
- Windows 端到端：`scripts/test-mount.ps1`（`-Protocol webdav|nfs|synology`，可加 `-ReadOnlyTest`），覆盖挂载、列目录、容量、中文文件读写改删、上传队列、在线探测、只读、卸载。
