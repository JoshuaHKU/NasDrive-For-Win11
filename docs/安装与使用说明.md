# NasDrive 安装与使用说明

本文适用于 NasDrive 0.5.x。第 1–7 节为 Windows 10 / 11（x64）版，第 8 节为 macOS 版（添加驱动器、各协议的 NAS 端设置两个平台相同）。

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 1809 及以上、Windows 11（64 位；家庭版、专业版均可） |
| 运行库 | 无需另装 .NET（已内置） |
| 文件系统驱动 | [WinFsp](https://winfsp.dev)，安装程序会自动安装 |
| 磁盘空间 | 程序约 100 MB；另需本地缓存空间（默认上限 10 GB/驱动器，可在设置中修改） |
| 权限 | 安装需要管理员权限（安装 WinFsp 驱动）；**使用时请以普通方式运行**，不要"以管理员身份运行" |

## 2. 安装

1. 从 [Releases](https://github.com/JoshuaHKU/NasDrive-For-Win11/releases) 下载 `NasDrive-x.y.z-x64-setup.exe`。
2. 双击运行。安装包暂未做代码签名，Windows SmartScreen 可能提示"已保护你的电脑"：点击 **更多信息 → 仍要运行**。
3. 选择安装位置与选项（桌面图标、开机启动），点击安装。若系统中没有 WinFsp，会自动静默安装；若 WinFsp 安装失败，安装程序会报错并停止，日志在 `%TEMP%\NasDrive-winfsp-install.log`。
4. 完成后启动 NasDrive，托盘区出现图标。关闭主窗口只会隐藏到托盘；退出请右键托盘图标 → 退出。

**升级**：直接运行新版本安装包即可，配置与密码会保留。安装程序会先结束正在运行的 NasDrive，**升级前请先在 NasDrive 中断开驱动器，确保上传队列已清空**。

**卸载**：设置 → 应用 → NasDrive → 卸载。WinFsp 会保留（其他软件也可能使用它），如不需要可单独卸载。

## 3. 添加驱动器

点击主窗口右上角 **添加**，先选择 **服务类型**，再填写对应信息，可先点 **测试连接**，最后点 **连接**。

通用选项：

| 选项 | 说明 |
|---|---|
| 虚拟驱动器 | 盘符与名称；名称会显示在资源管理器中，如 `资料 (Z:)` |
| 启动 NasDrive 后自动连接 | 开机/启动程序时自动挂载 |
| 只读 | 禁止任何写入、删除、改名（Windows 层面拒绝） |
| 模拟本地磁盘 | 默认作为网络驱动器；勾选后显示为本地磁盘（部分软件需要） |
| 超时 | 单次请求超时时间 |
| 高级 → 缓存模式 / 缓存上限 / 目录缓存时间 | 一般保持默认（full / 10G / 30s） |

### 3.1 群晖 Synology（推荐群晖用户使用）

直接使用 DSM 登录（File Station 接口），**NAS 上无需开启 WebDAV 或 NFS**。

1. 服务类型选 **群晖 Synology**。
2. 地址填 NAS 的 IP 或域名，勾选 HTTPS，端口 **5001**（不勾 HTTPS 则为 5000）——即 DSM 网页登录用的端口。
3. 填写 DSM 用户名和密码。NAS 使用自签名证书时勾选 **忽略证书错误**。
4. 点击 **列出共享**，在列表中点选共享文件夹；也可以直接在路径中填写 `/共享文件夹/子目录`。
5. 若该账户启用了**两步验证**，会弹出验证码输入框：输入验证器 App 中的 6 位验证码。NasDrive 会把本机登记为 DSM 的受信任设备（名称为 `NasDrive-电脑名`），之后连接不再需要验证码。可在 DSM **个人 → 安全性 → 两步验证 → 受信任的设备** 中随时撤销。

### 3.2 WebDAV

NAS 端：群晖在 **套件中心** 安装 **WebDAV Server** 并启用 HTTPS（默认端口 5006）；其他品牌请参照其 WebDAV 设置。

1. 服务类型选 **WebDAV**。
2. 地址、端口（群晖 HTTPS 为 5006），或直接粘贴完整 URL（如 `https://nas.example.com:5006/share`）。
3. 路径填要映射的目录，如 `/share/folder`；用户名、密码；自签名证书勾选 **忽略证书错误**。
4. 需要走代理时勾选 **代理**（代理服务器在 设置 → 代理 中配置）。

**Nextcloud / ownCloud**：勾选 **Nextcloud / ownCloud** 选项后，NasDrive 会自动使用 `https://服务器/remote.php/dav/files/<用户名>` 地址，路径框只需填写网盘内的文件夹（如 `/Documents`，留空为全部文件）。启用了两步验证的 Nextcloud 账户请在 Nextcloud 的 **设置 → 安全 → 设备与会话** 中创建"应用密码"，用它代替登录密码。

> 群晖 WebDAV 不返回容量信息，资源管理器会显示一个很大的默认容量；可在 高级 → 容量兜底 中填写实际容量（如 `4T`），或改用"群晖 Synology"类型。

### 3.3 SFTP

适用于任何开启了 SSH 的设备。NAS 端：群晖 **控制面板 → 终端机和 SNMP → 启用 SSH**，并在 **文件服务 → FTP → SFTP** 中启用 SFTP；Linux 服务器通常默认可用。

1. 服务类型选 **SFTP**，填地址与端口（默认 22）、用户名；路径填要映射的目录（如 `/home/bob/data`，群晖为 `/共享文件夹名`）。
2. 选择登录方式：
   - **密码登录**：填密码；
   - **私钥登录**：点 **浏览…** 选择私钥文件（OpenSSH 或 PEM 格式，例如 `C:\Users\你\.ssh\id_ed25519`），有口令就填口令，没有就留空。私钥文件保留在原处，NasDrive 只记住它的路径；口令保存在凭据管理器中。
3. 首次 **测试连接** 或 **连接** 时会弹出 **服务器指纹** 对话框：请与服务器上 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 的输出核对，一致后点 **信任并继续**。NasDrive 会固定这个密钥。
4. 以后若服务器密钥改变（可能是中间人攻击，也可能是服务器重装），NasDrive 会拒绝连接并显示红色警告。确认是正常更换后，可在编辑页点 **清除已信任的服务器密钥** 重新确认。

### 3.4 FTP / FTPS

1. 服务类型选 **FTP**，选择 **加密**：
   - **显式 FTPS**（推荐，端口 21）：先建立普通连接再升级为 TLS，大多数服务器支持；
   - **隐式 FTPS**（端口 990）：一开始就是 TLS 连接；
   - **不加密**：用户名、密码和文件都会明文传输，仅限可信局域网。
2. 填地址、端口、用户名和密码，或勾选 **匿名**。
3. 服务器使用自签名证书时勾选 **忽略证书错误**。
4. 若提示"服务器不支持所选的加密方式"，请在显式与隐式之间切换并检查端口。

> FTP 协议不提供容量信息，可在 高级 → 容量兜底 中填写实际容量。

### 3.5 NFS

NFS 没有密码，按客户端 IP 授权，传输不加密，**只建议在可信局域网内使用**。

NAS 端（以群晖为例）：

1. 控制面板 → 文件服务 → **NFS**：勾选"启用 NFS 服务"。
2. 控制面板 → 共享文件夹 → 选中共享 → 编辑 → **NFS 权限** → 新增：
   - 主机名或 IP：本机 IP 或所在网段（如 `192.168.1.0/24`）；
   - 权限：可读写；
   - Squash：**映射所有用户为 admin**（最省事；否则需在 NasDrive 中填写与 NAS 用户一致的 UID/GID）；
   - 安全性：sys。
   NasDrive 默认从特权端口（<1024）连接，所以无需勾选"允许来自非特权端口的连接"。

NasDrive 端：

1. 服务类型选 **NFS**，填 NAS 地址。
2. 点击 **列出共享**，点选导出路径（如 `/volume1/share`）；可选填子目录。
3. UID/GID 按上面 Squash 设置填写（映射为 admin 时保持 0）。

## 4. 日常使用

- **主窗口**：每个驱动器一行，显示状态、容量与上传进度；可连接/断开、编辑、删除，或点击打开资源管理器。
- **托盘图标**：蓝色 = 有驱动器已连接；灰色 = 未连接；琥珀色 = 有驱动器离线或出错。右键菜单可快速连接/断开每个驱动器。
- **断开**：若还有文件在上传，会提示等待完成或强制断开（强制断开会丢失未上传的修改）。
- **网络中断**：驱动器变为"离线"，网络恢复后自动重新连接。

## 5. 设置

| 设置 | 说明 |
|---|---|
| 开机启动 | 登录 Windows 后自动启动（最小化到托盘） |
| 连接后打开资源管理器 | 每次连接成功后自动打开该盘 |
| 缓存目录 | 默认 `%LOCALAPPDATA%\NasDrive\Cache`，可改到空间更大的磁盘 |
| 读缓存保留时间 / 写回延迟 | 默认 1 小时 / 5 秒 |
| 代理 | HTTP 代理服务器（仅 WebDAV/群晖驱动器在勾选"代理"后使用） |
| 语言 | 中文 / English |

## 6. 数据与隐私

| 内容 | 位置 |
|---|---|
| 驱动器配置、设置（不含密码） | `%APPDATA%\NasDrive\profiles.json`、`settings.json` |
| 密码、群晖设备令牌、代理密码 | Windows 凭据管理器，目标名以 `NasDrive:` 开头 |
| 缓存 | `%LOCALAPPDATA%\NasDrive\Cache`（或设置中指定的目录） |
| 日志 | `%LOCALAPPDATA%\NasDrive\Logs`（日志中的密码会被自动替换为 `***`） |

NasDrive 只会连接你配置的 NAS，以及（若开启"自动检查更新"）GitHub 的 Releases 接口，不收集任何使用数据。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 连接成功但资源管理器里看不到盘符 | NasDrive 不能以管理员身份运行（新版会自动以普通身份重启）；检查是否被其他软件占用该盘符 |
| 提示"未检测到 WinFsp" | 重新运行安装程序，或从 winfsp.dev 安装 |
| 群晖：证书不受信任 | 勾选"忽略证书错误"（自签名证书） |
| 群晖：一直要求验证码 | 确认 DSM 中允许"受信任的设备"；撤销旧的 NasDrive 设备后重新连接 |
| 群晖：本机 IP 已被封锁 | 多次登录失败触发了 DSM 自动封锁：控制面板 → 安全性 → 保护 → 允许/封锁列表 中解除 |
| NFS：NAS 拒绝了本机 | 在共享的 NFS 权限中加入本机 IP/网段；跨网段时 NAS 看到的可能是路由器地址 |
| NFS：连接被拒绝 | NAS 未开启 NFS 服务，或防火墙拦截了 111/2049 端口 |
| SFTP：服务器密钥已改变 | 确认服务器确实更换了密钥后，在编辑页清除已信任的密钥再连接；否则不要连接 |
| SFTP：私钥无法读取或口令错误 | 确认私钥路径与口令；PuTTY 的 .ppk 格式需先用 PuTTYgen 导出为 OpenSSH 格式 |
| FTP：服务器不支持所选的加密方式 | 在显式 FTPS（21）与隐式 FTPS（990）之间切换 |
| WebDAV：405 | 路径不存在（群晖对不存在的共享返回 405），或端口不是 WebDAV 端口 |
| 升级失败（文件被占用） | 先在托盘中退出 NasDrive 再安装 |

仍无法解决时，请在 [Issues](https://github.com/JoshuaHKU/NasDrive-For-Win11/issues) 提交问题，并附上 `%LOCALAPPDATA%\NasDrive\Logs` 中的日志（请先检查并删除其中的地址等个人信息）。

## 8. macOS 版

### 8.1 系统要求与安装

| 项目 | 要求 |
|---|---|
| 操作系统 | macOS 12 及以上；Apple 芯片下载 `osx-arm64.dmg`，Intel 下载 `osx-x64.dmg` |
| 额外软件 | **无**：不需要 macFUSE、FUSE-T 或内核扩展，也不需要管理员密码 |
| 磁盘空间 | 程序约 150 MB；本地缓存在 `~/Library/Caches/NasDrive`（上限可在设置中修改） |

1. 打开 dmg，把 **NasDrive** 拖入"应用程序"。
2. 安装包暂未经 Apple 公证，首次打开请在 Finder 中**右键 NasDrive → 打开 → 打开**（之后可正常双击）。
3. NasDrive 是**菜单栏应用**：屏幕顶部菜单栏出现 NasDrive 图标，程序坞中不显示。点击图标打开主窗口，菜单里可直接连接/断开各驱动器。关闭窗口不会退出；退出请用菜单栏图标 → 退出。

### 8.2 驱动器在哪里

macOS 没有盘符，每个驱动器挂载为一个文件夹：`~/NasDrive/<驱动器名称>`（例如 `~/NasDrive/资料盘`）。连接后它会出现在 Finder 边栏的"位置"中，任何程序都可以像本地文件夹一样打开、保存。主窗口底部的"在 Finder 中打开"会打开挂载位置。

**为单个驱动器指定挂载位置**：在添加/编辑驱动器界面的"挂载位置"一栏填写或用"浏览"选择文件夹，例如 `~/NAS/资料`。该文件夹必须是空的或尚不存在（NasDrive 会自动创建）；如果"浏览"选中的是有内容的文件夹，会自动在其下使用以驱动器名称命名的子文件夹。不能与其他驱动器的挂载位置重叠，也不能是系统文件夹。留空（或点"默认"）则使用下述统一挂载位置下的同名子文件夹。修改已连接驱动器的挂载位置并保存时，会自动断开并在新位置重新连接。

**更改统一挂载位置**：在"设置 → 挂载位置"中填写或用"浏览"选择一个文件夹（例如 `~/NAS` 或外接磁盘上的文件夹），点"应用"。"默认"恢复为 `~/NasDrive`。要求：完整路径（以 `/` 或 `~` 开头），不能是系统文件夹或主目录本身，不能位于已连接的驱动器之内，且当前用户可写。如果有驱动器正在连接，NasDrive 会先询问，确认后断开它们并在新位置重新连接；若有文件正在使用导致无法断开，挂载位置保持不变。

原理：NasDrive 引擎在本机 127.0.0.1 上运行一个只供自己使用的 NFS 服务，由 macOS 自带的 NFS 客户端挂载（rclone `nfsmount`），因此无需第三方内核扩展。与 Windows 版一样，读写经过本地缓存，写入在后台上传到 NAS。

### 8.3 与 Windows 版的差异

| 项目 | 说明 |
|---|---|
| 密码存放 | macOS **钥匙串**（"钥匙串访问"中名为 NasDrive 的项目），不写入任何文件 |
| 开机启动 | 设置 →"登录时启动 NasDrive"（LaunchAgent：`~/Library/LaunchAgents/io.github.joshuahku.nasdrive.plist`） |
| 只读驱动器 | 系统层只读挂载，Finder 中无法新建、修改、删除 |
| macOS 元数据 | `._文件名`、`.DS_Store`、`.Trashes` 等文件**不会写入 NAS**；代价是 Finder 标签等扩展属性只在本次挂载期间有效，不会保存到 NAS（与 macFUSE 的 `noappledouble` 相同） |
| 文件名 | 统一以 NFC 形式保存，Windows 与 NAS 端看到的中文、带重音的文件名与 Mac 一致 |
| 引擎意外退出 | NasDrive 会自动重启引擎，清理失效的挂载并重新连接；此期间访问该文件夹会在数十秒内返回错误，而不会让 Finder 一直卡住 |

### 8.4 数据位置

| 内容 | 位置 |
|---|---|
| 配置（驱动器、设置） | `~/Library/Application Support/NasDrive/` |
| 日志 | `~/Library/Logs/NasDrive/` |
| 缓存 | `~/Library/Caches/NasDrive/`（可在设置中修改） |
| 挂载点 | `~/NasDrive/`（可在设置中修改） |

**卸载**：在菜单栏中退出 NasDrive，把"应用程序"中的 NasDrive 移到废纸篓；如需彻底清除，再删除上表中的文件夹，并在"钥匙串访问"中删除名为 NasDrive 的项目。

### 8.5 常见问题（macOS）

| 现象 | 处理 |
|---|---|
| 提示"无法打开，因为无法验证开发者" | 右键 NasDrive → 打开；或 系统设置 → 隐私与安全性 → 仍要打开 |
| 提示"未检测到系统 NFS 客户端" | macOS 自带 NFS 客户端；若被管理策略移除，请联系管理员 |
| 断开后挂载位置中残留空文件夹 | 可直接删除；下次连接会自动重建 |
| Finder 中驱动器显示为灰色或无法访问 | NAS 离线或引擎在重启：稍候自动重连，或在菜单中断开后重新连接 |

日志在 `~/Library/Logs/NasDrive`（提交 Issue 前请先删除其中的地址等个人信息）。
